Swapy 首个 Windows 10/11 x64 一键安装版本。

### 下载与启动

- **Swapy-0.1.0-windows-x64-setup.exe**：双击安装，完成后自动启动并打开浏览器；以后使用桌面或开始菜单快捷方式。
- **Swapy-0.1.0-windows-x64-portable.zip**：完整解压到可写目录，双击 Start Swapy.cmd。
- **SHA256SUMS.txt**：安装包、便携包和对应 OpenJDK 源码的校验值。
- OpenJDK 源码压缩包用于提供对应第三方源码，普通使用无需下载。

内置 Eclipse Temurin Java 17.0.21.1+2、SQLite JDBC、本地前端资源及词库，无需另装 JDK、Maven、Node.js、Python 或 Docker。运行时不需要联网下载依赖。本次不包含 LibreOffice。

默认入口为 http://127.0.0.1:4175/，目标浏览器为 Chrome/Edge 80+。
关闭浏览器不会停止服务，停止时使用 Stop Swapy.cmd。
同一端口已有其他实例时，请先停止原实例，或运行 "Start Swapy.cmd" -Port 4177。

### 内容

- 文件／目录扫描、固定四路并行、文件级扫描断点。
- 一对一可逆脱敏，默认标记平替，可选自然词平替。
- 密码本、密码包、任务报告与离线词库导入导出。
- 词库关键词、类别、词性、语言及状态筛选和服务端分页。
- 随包 V5：54,213 条平替词、540 条军事示例敏感词，包含电子战增量。
- 首次启动仅在空词库时初始化；已有词库与任务不覆盖。

安装版数据位于 %LOCALAPPDATA%\Swapy\data，升级与卸载保留。
便携版数据位于解压目录的 data，移动与备份时请一并保留。
存在执行中的任务时，安装器会提示先完成任务或暂停扫描。

### 支持边界

DOCX 直接修改文字；RTF/ODT 缺少可选转换引擎时明确报错。旧 DOC 明确报错。
PDF 只处理可安全改写的文本层；图片、OCR 和独立源码不在范围内，压缩包仅扫描。
复杂版式需以业务样例验收，未在历史 Chrome/Edge 80 二进制上实测。

军事词表是匹配示例，不是涉密认定清单。
ES/EA/EP 等短缩写可能在其他语境命中，可按需弃用；英文短语保持字面空格与连字符匹配。

第三方原始许可、对应源码入口、构建提交和文件校验清单保留在发行目录。
