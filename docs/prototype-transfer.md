# 原型导入导出约定

## 词库

JSON 词库格式 `swapy-library`，格式版本 1。包含发布版本、敏感库和平替库及其弃用状态。词条修改启用新 ID，旧词条保留。导入原子合并，拒绝版本降级、重复 ID、同 ID 跨库或词面/属性冲突，重复导入不重编号。弃用不可通过旧数据重新启用。

新增词条使用带 S/R 前缀的加密随机 UUID，登记已发放 ID，并检查已有两套词库和历史 ID；任务新建同样采用 T 前缀随机 ID。原型本地防重不代替正式跨设备权威登记：正式发布前必须经全局唯一约束确认，发生冲突重新分配后才允许发布下发。

## 脱敏任务

单任务 `.swapy` 为无损 ZIP，包含 `record.json`：格式 `swapy-prototype-task`、格式版本 1、类型 `redaction-task`、任务元数据和映射快照。原文文件及预览不打包。多个任务导出为 ZIP 合集，内部各任务单独 `.swapy`。

只允许已完成或部分完成的脱敏任务导出；扫描和还原任务不支持任务密码包导出。任务页可多选导出或导出本地全部可用密码包。导入可接收单包和批量合集，验证全部记录后提交；同 ID 同记录重复导入幂等，同 ID 异记录拒绝覆盖。

还原可上传密码包或输入本地脱敏任务 ID。导入包可先保存，但本地词库未达到包声明下限时不能开始还原，提示先同步或导入词库。映射快照保留，读取密码本不依赖原文预览。

## 边界与验证

当前编码是原型协议，正式压缩协议仍需设计。实际文件内容处理、真正的任务调度及断电恢复尚未实现。UI 与交换记录都仅在本机浏览器中演示。

验证命令：`node .impeccable/review/verify-transfer.cjs`。覆盖 1000 次 ID 防重、词库历史保留与冲突/降级拒绝、单包与批量回读、非脱敏任务拒绝、同 ID 冲突及幂等导入。

ZIP API 参考：[JSZip 官方加载文档](https://stuk.github.io/jszip/documentation/api_jszip/load_async.html)。依赖本地分发，浏览器运行不使用外网 CDN。
