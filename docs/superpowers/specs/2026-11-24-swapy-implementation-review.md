# 首版实现审核与修复记录

日期：2026-11-24。当前实现采用本地 Java 17 服务、SQLite 和浏览器页面；Docker 是可选部署方式。

## 审核结论的边界

设计独立审核已完成并据此实施。随后独立代码审核发现以下阻断和重要问题，原始审核不能视为直接通过；作者已逐项修复并增加回归验证，未再发起第二轮独立代码审核。当前交付为可运行的首版，格式覆盖和复杂版式仍需使用实际业务文档验收。

| 审核问题 | 最终处理 | 验证位置 |
| --- | --- | --- |
| 产物发布意图和成功映射分开提交，崩溃后可能丢失还原记录 | READY 产物、工作项 DONE、实际使用的映射和异常记录在同一 SQLite 事务提交 | RecoveryTest |
| 提取原文缓存位于可复制的任务目录 | 缓存迁到本机 data/work；写出尝试放到输出根的私有 .swapy-stage；公开任务目录仅保留报告及完整发布结果 | RecoveryTest、TaskServiceTest |
| SQL UNIQUE 字段引用未更新，组成员可能部分发布 | 补齐约束引用；无法安全绑定的语句使整个 SQL 组失败；整棵 files 树原子发布 | DocumentTest、TaskServiceTest、RecoveryTest |
| 归档输入链接、输出目录链接可能越界 | 解析、提取、写入和下载均检查真实路径；浏览器不暴露内部暂存目录 | StoreTest、TaskServiceTest（真实 NTFS 目录联接） |
| 发现阶段服务退出可能被误判为用户暂停 | 区分用户暂停、退出和中断，重开后继续原扫描任务 | RecoveryTest、TaskServiceTest |
| 未命中文档被重新序列化 | 无命中时逐字节复制 | DocumentTest |
| PDF 较短替换后无法还原较长原词 | 保留并复用内容流中的预留宽度，不能安全容纳则失败 | DocumentTest |
| 精简密码包可能伪造词条种类和最低版本 | 验证敏感库／平替库身份、属性和实际引入版本，整批原子导入 | PackageTest |
| 手工导入词库后 Git 版本链中断 | 允许带父版本／摘要的快照检查点，不伪造缺失历史版本；普通同步实例只读 | GitCatalogTest |
| 归档额度只在提取后统计，重开会重置 | 提取前持久预留并在展开过程中限制，任务累计预算保留 | ArchiveTest、TaskServiceTest |
| CSV 平替词包含分隔符可能破坏字段 | 按字段变换并按需引用、转义 | DocumentTest |
| DOCX 跨制表符、换行可能形成假敏感词 | 显式分段，保留跨普通文字 run 的匹配和样式映射 | DocumentTest |
| 页面不能显式绕过增量缓存 | 扫描增加“完整重扫” | 浏览器联调 |

## 本轮工程裁定

- 工作目录没有 Git 仓库，不擅自初始化或提交；以文件化设计、计划和开发台账记录变更。
- 用户已授权审核后直接开发，完成设计修订后内联实施，不重复要求确认。
- 默认文件选择器是网页内的已登记目录浏览器，访问 Java 主机／共享盘；无原文上传，也未引入原生桌面助手。
- 四路是整个进程共享的文件执行上限，扫描、脱敏、还原可以同时提交。
- 扫描提供文件级断点；脱敏、还原中断后保留已提交结果，重跑另建任务。
- 词库 Git 管理不自动推送远端；普通实例同步同一权威发布源，避免各设备发布相同版本号的分叉。
- 所有不安全或不支持的格式处理明确报错，不以原样文件冒充脱敏成功。

## 尚未验收的范围

DOC、RTF、ODT 需要 LibreOffice，本机缺少该引擎，转换链尚未完成本机真实验收。复杂 Office 排版、PDF 字体及内容流的广泛兼容性、复杂 Markdown 转义结构仍需样例测试。SQL 对无法可靠绑定的语句采用整组失败策略。

当前浏览器联调使用安装的 Chromium；页面按 Chrome/Edge 80+ 约束实现，但未在历史版本二进制上实测。Docker 配置可校验，不等同于镜像运行验收。发行脚本支持可分发 JDK 生成运行时，本轮开发包依赖系统 Java 17，未附带第三方运行时。
