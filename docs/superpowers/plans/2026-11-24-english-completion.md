# English library completion implementation plan

**Goal:** 补充英文人名／地点、常用词形、同词多词性候选，并保持旧ID和任务一对一还原。

**Architecture:** 继续Java17／SQLite／CSV，不添加自动词性推断。平替候选按词面＋词性＋语言形态＋粗类别去重；敏感词仍按词面唯一，运行时不同映射不可使用相同平替词面。词形用显式语言形态区分，敏感词按已配置形态匹配；不把一个基础词自动扩展到所有变形。

**Scope:** 人名和地点使用中性合成英文名称，常用英文复数及动词第三人称／过去式／过去分词／现在分词。规则生成只选可明确处理的基础词，常用不规则动词采用固定词形词典与覆盖表。每个新增声明属性组至少600候选；不承诺每个长度600或完整英语语法覆盖。保留原30,600记录及来源许可。

此前用户已要求后续不逐项提问、审核后开发，且本轮已批准三项范围；按既有技术执行，不增加审批环节。
