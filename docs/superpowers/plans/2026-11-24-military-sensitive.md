# Military example sensitive library plan

用户要求填充首批敏感库，以军事词汇为示例；此前已授权持续开发、正式库导入及两个仓库推送，不再逐项提问。

**范围：** 人工整理公开通用中英文术语、词性与粗属性；不用实际部队番号、人名、坐标、IP、具体编号。沿用七类，不按军兵种扩张分类。此为用户自定义匹配示例，不是官方涉密认定清单。

**实现：** 小型人工维护CSV作为敏感种子；主CSV追加S_UUID记录并保留全部旧ID、来源与许可，版本递增，重复生成稳定。敏感词面保持唯一。报告逐词匹配可用候选、长度与冲突；不为敏感条目机械凑500条。映射引擎排除可被启用敏感库再次命中的平替结果，原任务既有映射保持原样供还原。

- [x] 整理种子，生成完整兼容CSV及候选覆盖报告；测试与审核。
