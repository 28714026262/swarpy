# Swapy 交互原型

所有任务使用演示数据，不包含正式文件转换或密码包协议。扫描检查点使用浏览器本地存储，可演示刷新后继续扫描；正式断电恢复须由服务端持久化任务与已完成文件。

## 打开

无需安装前端依赖，也可双击 `index.html`。推荐在仓库根目录启动静态服务：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

访问 http://127.0.0.1:4173。

## Docker

仓库根目录执行：

```powershell
docker compose up -d --build
```

访问 http://127.0.0.1:4174。当前容器仅托管原型静态资源。正式 B/S 版本需另行接入后端文件处理、任务登记、词库同步、密码包接口和持久存储。原型端口只绑定本机。

## 体验流程

1. 扫描使用原生系统文件夹选择器，选定后立即运行。原型仅获取文件元数据，无上传和真实内容处理；本地文件不被错误标为已脱敏或安全。
2. 扫描、脱敏、还原为独立页面，可同时运行。步骤和进度在各自配置页，支持暂停、刷新续跑；脱敏和还原有输入与输出目录。
3. 结果仅展示敏感词命中、读取失败、未扫描等异常项，正常文件不列出；成功映射由密码本呈现。
4. 可下载演示 HTML 结果报告、HTML/JSON 密码本；“密码包接口示例”下载演示元数据 JSON，不是正式压缩包。
5. 还原使用“示例密码包”可触发词库版本过低场景，点击同步词库后继续。
6. 词库页可新增、弃用词条及同步版本，均仅影响演示内存状态。

页面铺满窗口，没有服务设置、布局切换栏或独立分析页面。任务记录仅放在任务页。系统文件夹为空时原生浏览器选择器可能不返回文件列表，正式本地访问方案留待后端设计。

## 兼容目标与资源

用户指定 Chrome/Edge 80+。使用本地 React 17.0.2、ReactDOM 17.0.2、Ant Design 4.24.16、Moment 2.30.1 UMD；没有外部 CDN、在线字体或图像依赖。使用 Flex/Grid 等基础布局，避免 `:has`、容器查询、File System Access、CompressionStream 等较新的特性。

实际浏览器验证以本机可用版本为准，不将当前浏览器通过等同于 Chrome 80 实机验证。

Ant Design 4 的兼容说明：https://4x.ant.design/docs/react/migration-v4 。第三方许可证随 `vendor/` 附带。

## 固定并行与数据迁移

- 并行固定 4 路，页面不提供调整。
- 还原支持上传密码包或输入本地脱敏任务 ID；未找到记录或词库版本不足时阻止开始并提示。
- 词库支持 JSON 导入导出，新词条使用加密随机 UUID 并登记防重；导入保留 ID，冲突拒绝，历史只弃用。
- 任务页仅支持脱敏任务密码包迁移。可多选、导出全部，或导入单个 `.swapy` 与 ZIP 合集；扫描和还原任务不可选作密码包导出。
- 原型数据交换实现见 `transfer.js` 和 `docs/prototype-transfer.md`；正式发布端还须接入全局 ID 唯一约束，正式密码包协议尚未定稿。
